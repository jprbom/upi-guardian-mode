# UPI Guardian Mode Design

## Product Thesis

A governance layer that evaluates AI-agent payment requests against user consent policies, merchant trust, prompt-injection risk, unusual timing, and bounded authority before simulated UPI money movement.

## UX

The first screen is a usable role-aware product console, not a landing page.

## Backend

Express provides validated APIs, demo RBAC, rate limits, security headers, synthetic persistence, and a domain decision engine.
